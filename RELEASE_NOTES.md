# Лампик v0.3.0-beta.1 — предварительная версия

Первый тестовый Windows-релиз компактного таймера выключения компьютера с персонажем-лампочкой.

## Что входит

- Маленькое плавающее окно (300 px), мини-режим и закрепление поверх окон
- Тёмная тема по умолчанию, мягко пульсирующее свечение лампочки
- Команды на русском без облачных сервисов: «выключи через 30 минут», «сон через час», «перезагрузи в 23:00», «отмени»
- Настраиваемые глобальные горячие клавиши (включая двухэтапные комбинации)
- Таймер и предупреждение за минуту; работа в системном трее

## Файлы

- **Lampik-Setup-0.3.0-beta.1-win-x64.exe** — установщик для Windows 10/11 x64
- **Lampik.exe** — переносимый автономный исполняемый файл

Установщик не имеет цифровой подписи, поэтому Microsoft SmartScreen может показать предупреждение. Проверяйте издателя и происхождение файла.

## Известные ограничения

- **Pre-release:** поведение на пользовательских ПК ещё не подтверждено; сохраняйте несохранённую работу перед проверкой выключения.
- Таймер действует, пока компьютер включён и Лампик запущен; не является задачей Планировщика Windows.
- Глобальные клавиши могут конфликтовать с другими программами.
- В этой версии нет автообновления и цифровой подписи.

Пожалуйста, сообщайте об ошибках в разделе Issues. Не используйте beta для критически важных задач.
